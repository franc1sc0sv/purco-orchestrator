How this report is written

Always

  • The verdict in plain sentences: did it finish, and if not, what stopped it.
  • Four numbers, and only four.
  • The ten checks, each with the measurement that proves it.
  • Guarantees written as behaviour a person would say out loud, never as a file or a test name.
  • Every waiver and every signed equivalence claim, with who signed it.

Never

  • Test-name dumps or file trees.
  • Logs, stack traces or command output.
  • A chronology of what the agents did.
  • Token counts anywhere but the footer.
  • Line or branch coverage percentages.
  • Praise, hedging or apology.

If a sentence does not change a decision the reader is about to make, it does not belong in the report.
