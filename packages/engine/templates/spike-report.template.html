How to run it

Each step has a gate that is code, not a sentence in a prompt. A phase that is not ready refuses to start.

  1. Open the worktree session

    cd {{REPO}} then claude. An MCP server only registers at session start, so step 2 is untestable in any older session.

  2. Build the MCP entrypoint

    purco-orchestrate mcp, registered in .mcp.json, with the human path moved from readline to MCP elicitation. Sampling is deprecated in protocol 2026-07-28 and asks the model, not you.

    Gate: a test agent asks at level human and the form appears in the session
  3. Re-run the census

    Deterministic, no agent, no cost. Fills the 529 site rows so no agent can add work later; one that finds an unlisted file raises a census gap instead.

    Gate: both self-checks read OK — every row clustered, no cluster above 25
  4. Survey, one cluster per agent

    Serial, a fresh agent per cluster, write paths first. Each gets its worklist from SQLite and holds Read, Grep, Glob only — read-only by allowlist, not by request.

    Gate: finish refuses while any site is untriaged; triage refuses unless occurrences read equals occurrences found
  5. Audit every finding

    The checker gets the claim and the file, never the surveyor's reasoning. It re-derives each one and rejects what it cannot reproduce. A large rejected pile is the expected result.

    Gate: audit cannot start while a site is untriaged
  6. Synthesize and score

    Inventory, write-path report, removal order and the ADR that no existing ADR covers. Then run the eval against the 17 hand labels to see whether the survey agreed with ground truth.

    Gate: synthesize cannot start while a finding lacks a verdict

What this does not cover

The gates prove the census was consumed. They do not prove it was complete. Those are different claims.
